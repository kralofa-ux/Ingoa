# Ingoa: Pacific Names

i want to create an app. Ingoa is a swipe-based baby name app focused on Polynesian names, starting with Cook Islands and Samoa. Individuals or couples can browse culturally meaningful names, like or pass on them, and if using couple mode, see the names they both match on in a shared list. Each name includes its meaning, culture, and gender, making it a simple, modern tool designed to help families choose and preserve Pacific names for the next generation.
